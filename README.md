Tugas Pemrograman Java
Membuat Sistem? Perpustkaan sederhana 
terdiri dari tiga class :
1. Class Buku
   Field: judul, pengarang, tahunTerbit
   constructor untuk inisialisasi objek buku
   method untuk menampilkan buku
2. Class AnggotaPerpus
   Field: nama, nim
   constructor this untuk inisialisasi atribut
   menampilkan informasi buku yang dipinjam dari class Buku
3. Perpustakaan (Main Class) untuk menjalankan programnya
   Ada dua objek buku dan dua objek anggotaPerpus dalam method main

   Pakai NetBeans
